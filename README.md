# Splat Sequence AR

15-frame Gaussian-splat animation (Apple SHARP → SPZ v3) played in the browser with
three.js + Spark 2.4.0. On iPhone it overlays the rear camera with rotation-only tracking
(iOS Safari has no WebXR). Desktop uses orbit controls.

- `frames/` — 150k splats/frame · `frames-lite/` — 75k splats/frame (`?lite=1`)
- Gestures (camera mode): 1-finger drag = yaw, pinch = scale, 2-finger drag = move.
